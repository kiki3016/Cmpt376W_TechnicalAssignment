geolib

A Python library for working with geographic information: points, polygons, tracks, and GPX data. Clean, composable, and easy to use.

Get Started API Reference

Overview

geolib provides the building blocks for geographic information systems (GIS) applications. It handles the tricky parts of working with geographic coordinates so you can focus on your application logic.

The library is built around a small set of composable classes that represent geographic primitives. You can combine them to implement a wide range of GIS functionality—from finding the farthest pair of points in a dataset, to checking whether a coordinate falls inside a country's borders, to processing GPS tracks from wearable devices.

Core Classes

📍

Point2D

A geographic coordinate with latitude and longitude.
🗻

Point3D

A 3D coordinate that adds elevation to Point2D.
🔲

BoundingBox

An axis-aligned geographic rectangle used for spatial filtering.
🗺️

Polygon

A closed region defined by an ordered list of vertices.
🛤️

Track

An ordered sequence of points representing a journey or path.
📂

GpxParser

Reads GPX files and returns structured GpxData.
📦

GpxData

Container for all data extracted from a GPX file.

Quick Example

Install the library, then import the classes you need:

from geolib import Point2D, Polygon, Track, GpxParser

# Create two geographic points
vancouver = Point2D(49.2827, -123.1207)
seattle   = Point2D(47.6062, -122.3321)

# Straight-line distance in metres
dist = vancouver.distance_to(seattle)
print(f"Vancouver → Seattle: {dist / 1000:.1f} km")
# Vancouver → Seattle: 232.8 km

# Check whether a point lies inside a polygon
border = Polygon([
    Point2D(49.0, -123.5),
    Point2D(49.0, -122.5),
    Point2D(49.5, -122.5),
    Point2D(49.5, -123.5),
])
print(border.contains(vancouver))   # True
print(border.contains(seattle))     # False

Design Philosophy

  • Composable primitives. Each class does one thing well. Build complex operations by combining them.
  • No side effects. Methods that compute new geographic values return new objects; they do not modify their inputs.
  • Consistent units. Distances are always in metres. Angles are always in degrees. Elevations are always in metres above datum.
  • Graceful 2D/3D mixing. Point3D is a subclass of Point2D. Methods that accept Point2D also accept Point3D; elevation is used when both operands carry it.
