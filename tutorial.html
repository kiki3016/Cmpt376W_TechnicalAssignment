Tutorial

This tutorial walks through the most common geolib use-cases with working code examples. By the end you will know how to create and measure geographic points, test whether a point falls inside a polygon, analyse a GPS track, and parse a GPX file.

1. Working with Geographic Points

Creating points

A Point2D holds a latitude (−90 to 90) and a longitude (−180 to 180). A Point3D extends it with an elevation in metres above datum. 

from geolib import Point2D, Point3D

# 2-D points (most common)
paris  = Point2D(48.8566, 2.3522)
london = Point2D(51.5074, -0.1278)

# 3-D point on Mont Blanc
mont_blanc = Point3D(45.8326, 6.8652, 4808.0)

Measuring distance

distance_to returns the great-circle distance between two points in metres. When both points are Point3D instances, the elevation difference is also taken into account (straight-line 3-D distance). 

dist_km = paris.distance_to(london) / 1000
print(f"{dist_km:.1f} km")   # 341.6 km

Bearing between points

bearing_to returns the initial compass bearing from one point to another, in degrees (0 = North, 90 = East, 180 = South, 270 = West). 

bearing = paris.bearing_to(london)
print(f"{bearing:.1f}°")   # 334.0° (roughly north-northwest)

Finding the midpoint

mid = paris.midpoint(london)
print(mid)   # Point2D(lat=50.18, lon=1.10)

Translating a point

translate(distance, bearing) returns a new point that is distance metres away from the original in the given bearing direction. Useful for generating test data or constructing circular regions. 

# Point 500 m north of Paris
north_of_paris = paris.translate(500, 0)

Tip: All distance values in geolib are in metres. Divide by 1 000 for kilometres.

2. Working with Polygons

A Polygon represents a closed geographic region defined by an ordered list of vertices. The most common operation is testing whether a point falls inside the region.

Creating a polygon

from geolib import Polygon

# Simplified border of a small square region
region = Polygon([
    Point2D(49.0, -123.5),
    Point2D(49.0, -122.5),
    Point2D(49.5, -122.5),
    Point2D(49.5, -123.5),
])

Point-in-polygon test

contains(point) uses the ray-casting algorithm and returns True if the point lies inside (or on the boundary of) the polygon. 

vancouver = Point2D(49.2827, -123.1207)
seattle   = Point2D(47.6062, -122.3321)

region.contains(vancouver)   # True
region.contains(seattle)     # False

Practical example: finding Wikipedia articles within a country

Suppose you have a Polygon describing Canada's border and a list of geotagged Wikipedia coordinates. You want all articles whose coordinates fall inside Canada. 

# canada_border: Polygon loaded from a data file
# articles: list of (title, Point2D) tuples

inside_canada = [
    title
    for title, point in articles
    if canada_border.contains(point)
]

Polygon measurements

region.perimeter()        # total boundary length, metres
region.area()             # enclosed area, square metres
region.bounding_box()    # BoundingBox that tightly encloses the polygon
region.vertex_count()    # 4

3. Working with Bounding Boxes

A BoundingBox is an axis-aligned rectangle defined by its north, south, east, and west edges. Bounding-box tests are much faster than full polygon tests, so they are a good first filter. 

from geolib import BoundingBox

# Construct directly
box = BoundingBox(north=49.5, south=49.0, east=-122.5, west=-123.5)

# Or derive it from a collection of points
points = [vancouver, seattle, paris, london]
box = BoundingBox.from_points(points)

box.contains(vancouver)   # True
box.center()              # midpoint of the box

Performance tip: When filtering a large point set against a complex polygon, first call polygon.bounding_box().contains(point). Only call the more expensive polygon.contains(point) for points that pass the bounding-box check.

4. Working with Tracks

A Track is an ordered sequence of geographic points representing a continuous journey—a hike, a bike ride, a drive. Tracks can consist of Point2D or Point3D objects (or a mix).

Creating a track

from geolib import Track, Point3D

hike = Track([
    Point3D(49.2827, -123.1207, 0.0),
    Point3D(49.3000, -123.1500, 120.0),
    Point3D(49.3200, -123.1800, 350.0),
    Point3D(49.3100, -123.2000, 280.0),
], name="Grouse Mountain Hike")

Distance and elevation statistics

hike.total_distance()      # total path length, metres
hike.elevation_gain()      # total ascent, metres
hike.elevation_loss()      # total descent, metres
hike.highest_point()       # Point3D with maximum elevation
hike.lowest_point()        # Point3D with minimum elevation

Segment distances

segment_distances() returns a list of distances between consecutive points. This is useful for detecting large gaps (GPS signal loss) or for time–distance charts. 

segments = hike.segment_distances()
# [2134.2, 3021.5, 1423.8]  (metres, one value per consecutive pair)

Practical example: exporting a track for Google Maps

Google Maps Directions accepts an array of {lat, lng} objects. Here is how to convert a Track to that format. 

def to_google_path(track: Track) -> list[dict]:
    return [
        {"lat": p.latitude, "lng": p.longitude}
        for p in track.points
    ]

path = to_google_path(hike)

Simplifying a track

GPS devices often record far more points than a map needs to draw. simplify reduces the number of points while preserving the shape of the path (Ramer–Douglas–Peucker algorithm). The tolerance parameter controls the maximum allowed deviation in metres. 

simplified = hike.simplify(tolerance=20)   # 20 m tolerance
print(len(hike.points), "→", len(simplified.points), "points")

5. Parsing GPX Files

GPX (GPS Exchange Format) is the standard XML format produced by GPS devices, fitness trackers, and mapping apps. GpxParser reads a GPX file and returns a GpxData object containing tracks, waypoints, and routes. 

from geolib import GpxParser

data = GpxParser.parse("my_run.gpx")

print(f"Tracks:    {len(data.tracks)}")
print(f"Waypoints: {len(data.waypoints)}")
print(f"Routes:    {len(data.routes)}")

# Analyse the first track
track = data.tracks[0]
print(f"Distance: {track.total_distance() / 1000:.2f} km")
print(f"Gain:     {track.elevation_gain():.0f} m")

Parsing from a string

If you already have the GPX content in memory (e.g. downloaded via HTTP), use parse_string instead. 

import urllib.request

url = "https://example.com/route.gpx"
with urllib.request.urlopen(url) as response:
    xml_content = response.read().decode()

data = GpxParser.parse_string(xml_content)

6. Finding the Farthest Pair of Points

geolib does not provide a "farthest pair" function directly, but Point2D.distance_to makes it easy to write one. 

from itertools import combinations

def farthest_pair(points):
    """Return the pair (a, b) from points that are farthest apart."""
    return max(
        combinations(points, 2),
        key=lambda pair: pair[0].distance_to(pair[1])
    )

cities = [paris, london, vancouver, seattle]
a, b = farthest_pair(cities)
print(f"Farthest: {a} – {b}")
