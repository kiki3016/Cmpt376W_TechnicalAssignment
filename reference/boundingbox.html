BoundingBox

An axis-aligned geographic rectangle defined by its north, south, east, and west edges. Bounding boxes are commonly used for fast spatial filtering before more expensive operations such as polygon containment tests.

Anti-meridian note: BoundingBox does not handle regions that span the 180° anti-meridian (e.g. a box covering Fiji). If your region crosses the anti-meridian, split it into two boxes.

Constructor

class BoundingBox(north: float, south: float, east: float, west: float)

Create a bounding box from its four edges.

ParameterTypeDescription
northfloatMaximum latitude (top edge). Must be ≥ south.
southfloatMinimum latitude (bottom edge).
eastfloatMaximum longitude (right edge). Must be ≥ west.
westfloatMinimum longitude (left edge).

Raises: ValueError if north < south or east < west.

box = BoundingBox(north=49.5, south=49.0, east=-122.5, west=-123.5)

Properties

north → float

Maximum latitude (northern edge). Read-only.

south → float

Minimum latitude (southern edge). Read-only.

east → float

Maximum longitude (eastern edge). Read-only.

west → float

Minimum longitude (western edge). Read-only.

Class Methods

@classmethod
from_points(points: list[Point2D]) → BoundingBox

Creates the smallest BoundingBox that contains every point in points.

ParameterTypeDescription
pointslist[Point2D]A non-empty list of geographic points. May contain Point3D values (elevation is ignored).

Returns: A new BoundingBox.

Raises: ValueError if points is empty.

cities = [paris, london, berlin, madrid]
box = BoundingBox.from_points(cities)

Methods

contains(point: Point2D) → bool

Returns True if point falls within (or on the boundary of) this bounding box.

ParameterTypeDescription
pointPoint2DThe point to test. May be a Point3D (elevation is ignored).

Returns: bool.

box.contains(paris)    # True
box.contains(toronto)  # False
center() → Point2D

Returns the geographic centre of the bounding box as a Point2D.

box.center()   # Point2D(lat=49.25, lon=-123.0)
expand(point: Point2D) → BoundingBox

Returns a new BoundingBox that is the smallest box containing both this box and point. If point already falls inside this box the original box is returned unchanged.

ParameterTypeDescription
pointPoint2DThe point to include. May be a Point3D.

Returns: A new BoundingBox. This box is not modified.

intersects(other: BoundingBox) → bool

Returns True if this box and other overlap (share any area or edge).

Special Methods

__eq__(other: object) → bool

Returns True if other is a BoundingBox with identical north, south, east, and west values.

__repr__() → str

Returns a string such as BoundingBox(N=49.5, S=49.0, E=-122.5, W=-123.5).
