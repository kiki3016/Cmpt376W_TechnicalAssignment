Point3D

A three-dimensional geographic coordinate that extends Point2D with an elevation value (metres above datum, approximately sea level). Point3D is a subclass of Point2D, so it is accepted everywhere a Point2D is expected.

Elevation vs altitude: Elevation is measured relative to the WGS-84 geoid (approximately sea level), not the ground surface. A negative elevation indicates a point below sea level (e.g. the Dead Sea shores at roughly −430 m).

Constructor

class Point3D(latitude: float, longitude: float, elevation: float)

Create a 3-D geographic point.

ParameterTypeDescription
latitudefloatDegrees north (+) or south (−). Range: −90 to 90.
longitudefloatDegrees east (+) or west (−). Range: −180 to 180.
elevationfloatHeight above datum in metres. May be negative.

Raises: InvalidCoordinateError if latitude or longitude is out of range.

summit = Point3D(45.8326, 6.8652, 4808.0)   # Mont Blanc

Properties

Inherits latitude and longitude from Point2D.

elevation → float

The elevation of this point in metres above datum. Read-only. May be negative.

Overridden Methods

distance_to(other: Point2D) → float

Returns the distance between this point and other in metres.

  • If other is a Point3D: returns the straight-line 3-D Euclidean distance, computed as sqrt(great_circle² + elevation_diff²).
  • If other is a plain Point2D: falls back to the great-circle (Haversine) distance, ignoring elevation.
base  = Point3D(45.83, 6.86, 1000.0)
summit = Point3D(45.83, 6.87, 4808.0)
base.distance_to(summit)   # includes 3808 m elevation gain

Additional Methods

elevation_difference(other: Point3D) → float

Returns other.elevation − self.elevation. A positive result means other is higher; a negative result means other is lower.

ParameterTypeDescription
otherPoint3DThe other point. Must be a Point3D.

Returns: Signed elevation difference in metres (float).

base.elevation_difference(summit)   # +3808.0
summit.elevation_difference(base)   # -3808.0

Special Methods

__eq__(other: object) → bool

Returns True if other is a Point3D with identical latitude, longitude, and elevation. A Point3D and a Point2D at the same lat/lon are not considered equal.

__repr__() → str

Returns a string such as Point3D(lat=45.8326, lon=6.8652, elev=4808.0).
