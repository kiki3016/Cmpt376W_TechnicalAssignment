Track

An ordered sequence of geographic points that represents a continuous journey, route, or path—such as a hike, a bike ride, or a drive. A Track may contain Point2D or Point3D points (or a mix of both).

Elevation-related methods (elevation_gain, elevation_loss, highest_point, lowest_point) are only meaningful when the track contains Point3D points.

Constructor

class Track(points: list[Point2D], name: str = None)

Create a track from an ordered list of geographic points.

ParameterTypeDescription
points list[Point2D] At least 2 geographic points in traversal order. May contain Point3D values.
name str optional A human-readable name for the track (e.g. from a GPX file). Defaults to None.

Raises: ValueError if fewer than 2 points are supplied.

hike = Track([
    Point3D(49.28, -123.12, 0),
    Point3D(49.30, -123.15, 120),
    Point3D(49.32, -123.18, 350),
], name="Grouse Grind")

Properties

points → tuple[Point2D, ...]

An immutable sequence of the track's points in traversal order. Read-only.

name → str | None

The name of the track, or None if none was provided. Read-only.

Distance Methods

total_distance() → float

Returns the total length of the track in metres, calculated as the sum of the distances between all consecutive point pairs. For Point3D tracks the distance between each consecutive pair accounts for elevation change (3-D Euclidean distance). 

hike.total_distance()   # total path length, metres
segment_distances() → list[float]

Returns a list of distances (in metres) between each consecutive pair of points. The list has len(track.points) − 1 elements. 

hike.segment_distances()
# [2134.2, 3021.5, ...]  one distance per consecutive pair
bounding_box() → BoundingBox

Returns the smallest BoundingBox that encloses all of the track's points.

Elevation Methods

These methods require the track's points to be Point3D instances. If any point lacks an elevation (i.e. is a plain Point2D), that point is skipped in the calculation. If no points have elevation, the method returns 0.0.

elevation_gain() → float

Returns the total uphill elevation gain in metres—the sum of all positive elevation differences between consecutive Point3D points. 

hike.elevation_gain()   # e.g. 350.0 m
elevation_loss() → float

Returns the total downhill elevation loss in metres as a positive number—the sum of the absolute values of all negative elevation differences between consecutive Point3D points. 

hike.elevation_loss()   # e.g. 70.0 m
highest_point() → Point3D | None

Returns the Point3D in the track that has the greatest elevation. If no Point3D points exist in the track, returns None. If multiple points share the maximum elevation, the first one (in traversal order) is returned.

lowest_point() → Point3D | None

Returns the Point3D in the track with the smallest elevation. Returns None if no Point3D points exist. If multiple points share the minimum elevation, the first one is returned.

Utility Methods

simplify(tolerance: float) → Track

Returns a new Track with fewer points that still approximates the shape of the original path, using the Ramer–Douglas–Peucker algorithm. The first and last points are always preserved.

ParameterTypeDescription
tolerance float Maximum allowable perpendicular distance in metres between a removed point and the simplified path. A larger tolerance removes more points; a tolerance of 0 returns an identical copy.

Returns: A new Track with the same name.

simplified = hike.simplify(tolerance=20)
print(len(hike.points), "→", len(simplified.points))

Special Methods

__len__() → int

Returns the number of points in the track. Allows len(track).

__iter__()

Iterates over the track's points in order. Allows for p in track: ....

__repr__() → str

Returns a string such as Track(name='Grouse Grind', points=142).
