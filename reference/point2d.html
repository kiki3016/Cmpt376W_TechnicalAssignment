Point2D

A two-dimensional geographic coordinate consisting of a latitude and a longitude. Point2D is the fundamental type in geolib; most functions accept (or return) a Point2D or its subclass Point3D.

Valid ranges: latitude must be in [−90, 90]. longitude must be in [−180, 180]. Constructing a Point2D with out-of-range values raises InvalidCoordinateError.

Constructor

class Point2D(latitude: float, longitude: float)

Create a 2-D geographic point.

ParameterTypeDescription
latitudefloatDegrees north (+) or south (−) of the equator. Range: −90 to 90.
longitudefloatDegrees east (+) or west (−) of the prime meridian. Range: −180 to 180.

Raises: InvalidCoordinateError if either value is out of range.

paris = Point2D(48.8566, 2.3522)

Properties

latitude → float

The latitude of this point in degrees. Read-only.

longitude → float

The longitude of this point in degrees. Read-only.

Methods

distance_to(other: Point2D) → float

Returns the great-circle (Haversine) distance between this point and other, in metres. If both points are Point3D instances, the returned value is the straight-line 3-D distance that also accounts for elevation difference.

ParameterTypeDescription
otherPoint2DThe point to measure the distance to. May be a Point3D.

Returns: Distance in metres (float).

paris.distance_to(london)   # 341 571.7 (metres)
bearing_to(other: Point2D) → float

Returns the initial compass bearing from this point toward other, in degrees (0 = North, 90 = East, 180 = South, 270 = West). The value is always in [0, 360).

ParameterTypeDescription
otherPoint2DThe target point.

Returns: Bearing in degrees (float), in [0, 360).

paris.bearing_to(london)   # 334.0 (north-northwest)
midpoint(other: Point2D) → Point2D

Returns the geographic midpoint on the great circle between this point and other. The returned point is always a Point2D (elevation is not interpolated even if both operands are Point3D).

ParameterTypeDescription
otherPoint2DThe other endpoint.

Returns: A new Point2D.

translate(distance: float, bearing: float) → Point2D

Returns a new Point2D that is distance metres away from this point in the direction of bearing. Uses the Haversine formula (spherical Earth).

ParameterTypeDescription
distancefloatDistance to travel, in metres. Must be ≥ 0.
bearingfloatDirection of travel, in degrees (0 = North).

Returns: A new Point2D.

# 1 km north of Paris
north = paris.translate(1000, 0)

Special Methods

__eq__(other: object) → bool

Returns True if other is a Point2D with the same latitude and longitude (exact float equality). For approximate comparisons, compare distance_to(other) < threshold.

__repr__() → str

Returns a human-readable string such as Point2D(lat=48.8566, lon=2.3522).

__hash__() → int

Point2D objects are hashable and can be used as dictionary keys or in sets. Two points that are equal (via __eq__) have the same hash.
