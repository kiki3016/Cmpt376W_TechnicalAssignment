GpxParser

Reads GPX (GPS Exchange Format) data from a file or string and returns a GpxData object containing the parsed tracks, waypoints, and routes.

GPX is an XML-based format produced by GPS devices, fitness trackers (Fitbit, Garmin, Apple Watch), and mapping applications. GpxParser supports GPX version 1.1 (the current standard) and GPX version 1.0.

Instantiation: GpxParser contains only static methods; you do not need to create an instance. Call GpxParser.parse(...) directly.

Static Methods

@staticmethod
parse(filename: str) → GpxData

Reads and parses a GPX file from disk. Elevation data (<ele>) is used when present; track points without elevation become Point2D objects while those with elevation become Point3D objects.

ParameterTypeDescription
filename str Path to the GPX file. Absolute or relative to the current working directory.

Returns: A GpxData object.

Raises:

  • FileNotFoundError — if the file does not exist.
  • GpxParseError — if the file is not valid GPX XML or is missing required elements.
data = GpxParser.parse("my_run.gpx")

print(f"Tracks:    {len(data.tracks)}")
print(f"Waypoints: {len(data.waypoints)}")

track = data.tracks[0]
print(f"Distance:  {track.total_distance() / 1000:.2f} km")
@staticmethod
parse_string(xml_content: str) → GpxData

Parses GPX data from an in-memory string. Useful when GPX content has been downloaded from the network, extracted from a ZIP archive, or generated programmatically.

ParameterTypeDescription
xml_content str A string containing valid GPX XML.

Returns: A GpxData object.

Raises: GpxParseError if the string is not valid GPX.

import urllib.request

with urllib.request.urlopen("https://example.com/route.gpx") as r:
    xml = r.read().decode()

data = GpxParser.parse_string(xml)

GPX Format Notes

A GPX file can contain three types of geographic data, all of which geolib reads:

  • Tracks (<trk>): A track is an ordered sequence of recorded positions, typically from a GPS receiver. Each track is returned as a Track. A GPX file may contain multiple tracks (e.g. separate days of a multi-day hike).
  • Waypoints (<wpt>): Named locations of interest (trailheads, summits, etc.). Each waypoint is returned as a Point2D or Point3D.
  • Routes (<rte>): Planned paths created by the user (rather than recorded from live movement). Each route is returned as a Track.

Track segments: GPX tracks may contain multiple <trkseg> segments (e.g. when a GPS device lost signal and then resumed). geolib concatenates all segments within a single <trk> element into one Track object. If you need to handle gaps between segments, inspect segment_distances() for unusually large jumps.
