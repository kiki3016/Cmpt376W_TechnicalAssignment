GpxData

A read-only container holding the geographic data extracted from a GPX file by GpxParser. It groups the data into three categories: tracks, waypoints, and routes.

You do not construct GpxData directly; it is always returned by GpxParser.parse() or GpxParser.parse_string().

Properties

tracks → tuple[Track, ...]

An immutable sequence of Track objects corresponding to the <trk> elements in the GPX file. Empty tuple if the file contained no tracks. 

for track in data.tracks:
    print(track.name, track.total_distance() / 1000, "km")
waypoints → tuple[Point2D, ...]

An immutable sequence of Point2D (or Point3D) objects corresponding to the <wpt> elements in the GPX file. Empty tuple if the file contained no waypoints. 

for wpt in data.waypoints:
    print(wpt)
routes → tuple[Track, ...]

An immutable sequence of Track objects corresponding to the <rte> (route) elements in the GPX file. Routes are planned paths, as opposed to recorded tracks. Empty tuple if the file contained no routes.

Methods

all_points() → list[Point2D]

Returns a flat list of every geographic point in the file: all track points, all waypoints, and all route points, in that order.

Useful for computing a single bounding box or doing a bulk containment check over everything in the file.

all_pts = data.all_points()
box = BoundingBox.from_points(all_pts)
print(f"Total points: {len(all_pts)}")

Special Methods

__repr__() → str

Returns a string such as GpxData(tracks=1, waypoints=3, routes=0).
