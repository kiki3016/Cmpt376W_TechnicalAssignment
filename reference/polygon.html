Polygon

A closed geographic region defined by an ordered list of vertices (geographic points). The boundary is formed by connecting each vertex to the next in order, with the last vertex connected back to the first.

A Polygon is intended to represent real-world geographic regions such as country or province borders, bodies of water, or administrative zones. The primary operation it supports is testing whether an arbitrary point lies inside the region.

Winding order: Vertices may be listed in either clockwise or counter-clockwise order; geolib normalises internally. Self-intersecting polygons produce undefined results from contains and area.

Constructor

class Polygon(vertices: list[Point2D])

Create a polygon from an ordered list of vertices.

ParameterTypeDescription
vertices list[Point2D] At least 3 geographic points. The polygon is automatically closed (you do not need to repeat the first point at the end). Point3D values are accepted; elevation is ignored.

Raises: ValueError if fewer than 3 vertices are supplied.

canada = Polygon([
    Point2D(60.0, -137.0),
    Point2D(60.0, -95.0),
    Point2D(49.0, -95.0),
    Point2D(49.0, -123.0),
    # ... real border data would have many more points
])

Properties

vertices → tuple[Point2D, ...]

An immutable sequence of the polygon's vertices in the order they were provided. The closing edge (last-to-first vertex) is implicit and not represented here.

Methods

contains(point: Point2D) → bool

Returns True if point is inside (or exactly on the boundary of) this polygon. Uses the ray-casting algorithm, which is correct for simple (non-self-intersecting) polygons.

ParameterTypeDescription
pointPoint2DThe point to test. Point3D is accepted; elevation is ignored.

Returns: bool

canada.contains(Point2D(45.4215, -75.6972))   # True  (Ottawa)
canada.contains(Point2D(47.6062, -122.3321))  # False (Seattle)

Performance: Call bounding_box().contains(point) first as a fast pre-filter. Only proceed to contains for points that pass the bounding-box test.

perimeter() → float

Returns the total length of the polygon's boundary in metres, calculated as the sum of the great-circle distances between consecutive vertices (including the closing edge from the last vertex back to the first). 

canada.perimeter()   # total border length in metres
area() → float

Returns the approximate area enclosed by the polygon in square metres, computed using the spherical excess formula. The result is an approximation that becomes less accurate for very large polygons (continent scale). 

canada.area()   # ≈ 9.98e12 m² for a full border
bounding_box() → BoundingBox

Returns the smallest BoundingBox that encloses all of the polygon's vertices.

vertex_count() → int

Returns the number of vertices (equivalently, the number of edges).

canada.vertex_count()   # number of border points

Special Methods

__len__() → int

Equivalent to vertex_count(). Allows len(polygon).

__repr__() → str

Returns a string such as Polygon(vertices=4).
