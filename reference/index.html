API Reference

Complete documentation for every class and method in geolib. All distances are in metres, all angles in degrees, and all elevations in metres above datum.

Exceptions

class GeolibError(Exception)

Base class for all geolib exceptions. Catch this to handle any geolib error generically.

class InvalidCoordinateError(GeolibError)

Raised when a latitude, longitude, or elevation value is outside its valid range: latitude must be −90 to 90, longitude −180 to 180.

class GpxParseError(GeolibError)

Raised when a GPX file or string cannot be parsed (malformed XML, missing required elements, etc.).
